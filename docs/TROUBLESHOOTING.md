# Troubleshooting

Level 1 diagnostic entry points are jarvis --status, jarvis --doctor and jarvis --self-test.

Future diagnostics will cover Ollama/models, memory/database, tools/policy, Python/Node, browser, STT/TTS, microphone/speakers, vision, Git and Windows integration.

Diagnostics report capability-specific failures and do not imply that an unavailable optional capability is broken Core.
