# JARVIS Expansion Status

JARVIS is being expanded across all six cumulative levels. New modules stay behind stable contracts so the Ollama/text core remains usable while desktop, voice, vision, agents, automation and remote features mature.

Foundations added in this expansion include a 20-agent runtime contract, capability registry, integrated PyQt6 desktop conversation surface, ambient reactor, bounded recovery engine, provenance model, model-routing boundary, local scheduler, notification manager, clipboard intelligence, language detection boundary, plugin manifest model, artifact store, external-send confirmation gate and awareness snapshots.

A foundation is not marked TESTED until automated and Windows live verification has run.
